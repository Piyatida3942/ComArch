		ในโปรแกรมจะต้องรับค่า oprand ที่เก็บ adress จริง นำมาหารด้วย 4 ก่อนเก็บเข้า PC

	แสดง memory เป็นตารางได้แล้ว ถ้ามีค่าใน memory จะแสดงเป็นเลข hex 2 ตำแหน่ง ถ้าไม่มีถือว่าเป็น 0
	ให้ Constuctor ของ Instruction พิมพ์คำสั่งของแต่ละบรรทัดออกมาให้ดู

cpu_simulator_python-main32V4
	เพิ่มฟังก์ชัน isa.imm2int เพื่อรองรับข้อมูล immediate ได้ทั้งแบบ int และ hex ขึ้นต้นด้วย 0x
		น่าจะปรับเพิ่มให้รับ binary 0b ได้ด้วย
	เพิ่มโหมดแสดงค่า register แบบ hexa decimal เลือกได้ระหว่าง intกับhex กำหนดไว้ใน cpu.DISP_FORMAT = "HEX"
		ถ้าไม่ใช่ HEX จะแสดงแบบ int
	ปรับปรุงกรณีผิดพลาดของคำสั่งเดิมๆ ถ้าจะใช้งานต้องเอาเวอร์ชันสุดท้ายไปปรับใช้
		เช่น addi ให้ใช้ค่า 16 bit และพิจารณาเครื่องหมายว่าเป็นบอกหรือเป็นลบค่อยเอามาบวกัน
	เพิ่มคำสั่งอื่นอีกเล็กน้อย เช่น LUI load upper immediate เพื่อทดสอบการรับเข้าข้อมูลแบบ int และ hex ได้สะดวก
	ยังขาดอีกหลายคำสั่ง น่าจะเอาไปทำต่อได้แล้ว แค่ปรับเพิ่มคำสั่งก็น่าจะใช้การได้แล้ว

หมายเหตุ ควรใช้งานอย่างระมัดระวัง เนื่องจากรับ input ได้ไม่กี่รูปแบบ ต้องใส่ตามที่กำหนด
	ต่อไปควรจะแสดง memeory ในส่วน text (คำสั่ง) ได้ด้วย อ้างอิงตามค่า .ORG ได้เลย
	แต่จะต้องแปลง คำสั่งจาก text ให้เป็น machine code ก่อน
	ควรจะใช้ เทคนิค 2-pass เพื่อแปลง assembly เป็น machine code (assemble)
		ถ้าแปลงได้แล้วก็ไม่จำเป็นต้องใช้งาน text เลย ดึงจาก memory มารันเลยก็ได้

cpu_simulator_python-main32V6
	เพิ่มเติมคำสั่งอื่นๆ ที่จำเป็นหรือง่ายๆ ก่อน เช่น SLT (set lees than) เพื่อเขียนเงื่อนไข if ได้หลากหลาย (จริงๆ ก็ไม่ง่ายเท่าไหร่)
		เพิ่ม SLTI ตรวจสอบก่อนว่า imm >= 2**15 ให้ปรับเป็นเลขลบ 
			ถ้า rs เป็นเลขบวกเกิน rs >=2**31 ให้ปรับเป็นลบ
			ยังสับสนอยู่ว่าการเปรียบเทียบใช้ 32bit เทียบกับ 16bit หรือเปล่า 

		   SLTIU ตรวจสอบก่อนว่า operand เป็นเลขลบหรือไม่ ให้ปรับเป็นบวกทั้งคู่
				2**32-5 < 2**16-1 False ok เพราะ 32 เทียบกับ 16 bit เปรียบเทียบกันไม่ได้
			        2**32-5 < 1  	  False ok  ถูก (เพราะไม่คิดเครื่องหมาย)
				      5 < 2**16-1 True  ถูก (เพราะไม่คิดเครื่องหมาย)
	แสดง address ของแต่ละคำสั่งได้ตั้งแต่ก่อนเริ่ม execute
